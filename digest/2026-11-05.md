## 统一系统观解读

统一系统观是什么，见[关于页](/about/)。本期三篇论文都可在 arXiv 阅读；三条 arXiv 条目均未注明发表或评审情况 [1]、[2]、[3]。

**第 1 条：反复复用同一组网络层的语言模型把参数省下来之后，推理时保存的键与值信息能不能压到每元素不到 1 比特，同时把服务吞吐抬上去。**

背景：循环 Transformer 反复复用同一组层，用更少参数去接近更大非循环模型的表现；但每一步循环仍要存自己的键与值，键值（KV）缓存会随循环步数线性变长，成为主要显存瓶颈。摘要称循环模型的 KV 缓存沿循环轴高度冗余，且各循环步对量化的敏感度差别很大 [1]。（本站补充的通用解释：键值缓存一般指推理时保存已处理 token 的键与值状态、供后续步骤复用的显存结构；向量量化一般指把向量压成少量码本索引以降低存储与带宽；BF16 是一种 16 位浮点格式。）

Minsoo Cheong 与 Sungjoo Yoo 两位作者于 2026-11-03 在 arXiv 公开论文《LoopVQ: Sub 1-bit KV Cache Quantization for Looped Transformers》，提出 LoopVQ：沿多循环步联合编码通道，并微调码本以贴合全精度模型输出的 KV 缓存向量量化方法 [1]。

为什么重要：在每元素 0.5 比特时，LoopVQ 在 Ouro 与 Huginn 模型上，于通用、长链式思考与长上下文检索任务中超过现有面向标准 LLM 的 KV 缓存向量量化方法；与 TaSQ 组合后，在每元素 0.25 比特仍能保住相当一部分 BF16 精度 [1]。作者并在 SGLang 中实现 LoopVQ：32K token 上下文下解码时延约减半，并在 1.4B 与 2.6B 的 Ouro 模型上相对 BF16 基线把峰值服务吞吐最高分别抬到约 4.3 倍与 6.1 倍 [1]。

**第 2 条：不做训练、只计算部分位置关联的注意力方法，能不能靠更大的语义块，同时把长文本「生成前处理输入」与「随后逐步生成」都加速。**

背景：摘要介绍一种免训练稀疏注意力：为每个提示建键索引，把键聚成可跨非连续位置的大语义块；每个查询位置按块中心打分选块，再对块内原始键值做注意力。同选一块的查询一并处理，使 prefill 仍快；大块让中心打分与分组处理更便宜，从而在同一时间预算下能看更多 token [2]。（本站补充的通用解释：prefill 是生成答案前处理输入内容的阶段；解码是随后逐步生成答案的阶段；稀疏注意力一般指每个查询只对一部分键值计算注意力，而不是对全部位置。）

Sosuke Kobayashi、Shoichiro Yamaguchi 与 Seiya Tokui 三位作者于 2026-11-03 在 arXiv 公开论文《Coarse Semantic Blocks for Efficient Training-Free Sparse Attention》，在一块 NVIDIA H200 上评测混合 LLM Qwen3.5-4B 与 35B-A3B [2]。

为什么重要：计入建索引与用索引的开销后，相对稠密注意力的整模墙钟加速在 512K token 时为 prefill 2.3–2.4 倍、解码 1.7–2.0 倍，在 1M token 时 prefill 为 2.9–3.0 倍 [2]。35B-A3B 在五条 RULER 任务至 1M、LongBench-v2 总体，以及 MRCR 至 256K 上接近稠密注意力；4B 主要在多键检索上掉点，但仍在三项基准上超过时延相近的稠密 Qwen3.5-2B [2]。

## LoopVQ：亚 1 比特的循环模型 KV 缓存量化

**1. LoopVQ: Sub 1-bit KV Cache Quantization for Looped Transformers（LoopVQ：面向循环 Transformer 的亚 1 比特键值缓存量化）**

> At 0.5 bits per element, LoopVQ outperforms existing KV cache vector quantization methods for standard LLMs on general, long chain-of-thought reasoning, and long-context retrieval tasks with Ouro and Huginn models.
>
> 译文：在每元素 0.5 比特时，LoopVQ 在 Ouro 与 Huginn 模型上，于通用、长链式思考与长上下文检索任务中超过现有面向标准 LLM 的 KV 缓存向量量化方法。

按摘要末句改述（非逐字引文；原摘要此处含 LaTeX 倍号记号，故不放入直接引文块）：论文报告，LoopVQ 在 SGLang 上使 32K token 上下文中的解码时延接近减半，并使 1.4B 与 2.6B Ouro 模型相对 BF16 基线的峰值服务吞吐最高分别达到 4.3× 和 6.1× [1]。

## 粗粒度语义块：免训练稀疏注意力

**2. Coarse Semantic Blocks for Efficient Training-Free Sparse Attention（粗粒度语义块：高效的免训练稀疏注意力）**

> Including the cost of building and using the index, whole-model wall-clock speedups over dense attention are 2.3-2.4x for prefill and 1.7-2.0x for decoding at 512K tokens, and 2.9-3.0x for prefill at 1M.
>
